# rocket-pcblib

KiCad symbols, footprints and STEP models for CHIPS Alliance hardware projects.

Place this repository in your project's `library/` directory.
Register the required symbol and footprint libraries in KiCad's project library tables.

Repository models use `${KIPRJMOD}/library/...`.
Official models use `${KICAD10_3DMODEL_DIR}` and require the KiCad 10 3D libraries.

Contributions follow the applicable [KiCad Library Conventions](https://klc.kicad.org/).
